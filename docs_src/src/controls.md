# Controls

This page lists the mod's own controls and the Darkest Dungeon II game controls worth knowing.

Every mod key can be rebound from the game's Settings screen, **Mod keys** tab, keyboard and controller alike. A binding can hold several chords at once, and pad chords capture on release, so holding a trigger makes it the chord's modifier. Controller names below are what the mod itself speaks in the rebind rows (Xbox-style; A is the south button, Select is the small left-center button some pads label View or Back).

## Navigation

| Action | Default keyboard | Default controller | Function |
| --- | --- | --- | --- |
| Navigate up | Up Arrow | DpadUp | Move focus up |
| Navigate down | Down Arrow | DpadDown | Move focus down |
| Navigate left | Left Arrow | DpadLeft | Move focus left; adjust a slider or tab |
| Navigate right | Right Arrow | DpadRight | Move focus right; adjust a slider or tab |
| Next panel | Tab | RightShoulder | Jump to the next panel |
| Previous panel | Shift+Tab | LeftShoulder | Jump to the previous panel |
| Activate | Enter, Numpad Enter | A | Activate the focused item |
| Back | Escape | B | Back out, close, or open the pause menu |
| Jump to first | Home | LeftTrigger+LeftShoulder | First item of the list |
| Jump to last | End | RightTrigger+RightShoulder | Last item of the list |

## Kingdom Map

Points of interest work like say-the-spire2's map reviewer: a category of cells in reading order, and a filter for the ones you can actually reach. The cursor jumps; the category and filter keys only speak.

| Action | Default keyboard | Default controller | Function |
| --- | --- | --- | --- |
| Previous point of interest | , | Unbound | Jump the cursor to the previous cell of the current category |
| Next point of interest | . | Unbound | Jump the cursor to the next cell of the current category |
| First point of interest | Shift+, | Unbound | Jump the cursor to the category's first cell; silent when already there |
| Last point of interest | Shift+. | Unbound | Jump the cursor to the category's last cell; silent when already there |
| Previous category | [ | Unbound | Switch to the previous category with any cells, hear its count, and land on its first cell |
| Next category | ] | Unbound | Switch to the next category with any cells, hear its count, and land on its first cell |
| Reachable filter | \ | Unbound | Toggle between all cells and reachable ones: from the stagecoach, or from the hero you are choosing a destination for |

Categories, in order: inns, camps, sieges, stationed heroes, treasure, regions, cursed regions, quest regions, the boss, and underground access.

## Combat

Glances speak in place; your focus does not move. Enemy slots count from the front line, 1 through 4, and so do yours.

| Action | Default keyboard | Default controller | Function |
| --- | --- | --- | --- |
| Enemy 1-4 | 1, 2, 3, 4 | LeftTrigger + RightStickLeft / Down / Up / Right | That enemy's name and health |
| Enemy effects 1-4 | Shift+1 to Shift+4 | LeftTrigger + X / A / Y / B | That enemy's tokens, buffs, and debuffs |
| Enemy resists 1-4 | Ctrl+1 to Ctrl+4 | RightTrigger + X / A / Y / B | That enemy's resistances |
| Hero 1-4 | Q, W, E, R | LeftTrigger + LeftStickLeft / Up / Down / Right | That hero's name and health |
| Hero effects 1-4 | Shift+Q to Shift+R | LeftTrigger + DpadLeft / Up / Down / Right | That hero's tokens, buffs, and debuffs |
| Hero resists 1-4 | Ctrl+Q to Ctrl+R | RightTrigger + DpadLeft / Up / Down / Right | That hero's resistances |
| Acting combatant | S | LeftStickClick | Who is acting and how they are doing |
| Skill targets | T | Unbound | Everyone the focused skill could hit right now, with previews; on a grey skill, why it is grey |
| Turn order | Shift+T | LeftTrigger+LeftStickClick | The turn order |
| Inspector | I | Select | Open or close the inspector on the focused combatant |
| Inspector previous / next | A / D | LeftStickLeft / LeftStickRight | Cycle combatants while the inspector is open |
| Affinity glance | A | LeftTrigger+RightStickClick | The focused skill's or target's relationship consequences |

## Game Controls

These are the game's own defaults, unchanged by the mod, rebindable in the game's settings. On screens the mod captures, the game's keys are swallowed - the mod forwards the ones a screen advertises (C, M, I, Z and friends) through its own bindings above. On shared-keyboard screens (the road), the game's keys stay live alongside the mod's.

| Game action | Default keyboard | Function |
| --- | --- | --- |
| Pause | Escape | Pause menu |
| Skip / interact | Space | Skip cinematics, advance, interact on the road |
| Drive | W / S or Up / Down | Speed up, slow down |
| Steer | A / D or Left / Right | Steer the coach |
| Minimap | M or Tab | The road map |
| Goals panel | G | The biome goals panel on the road |
| Show torch | Alt (hold) | The flame readout on the road |
| Inventory | I or E | The bag |
| Hero sheet | C or Q | The character sheet |
| Relationships | R | The relationships panel on the road |
| Stagecoach | Z | The stagecoach sheet (crossroads: the Vitrine, via the mod's Z) |
| Token glossary | Ctrl (hold) | The token reference view |
| More info | X | Expanded tooltips where offered |
| Split stack | V | Split an item stack |
| Take all loot | Space or T | Grab everything on a loot screen |
| Combat skills | 1 through 0 | Use that skill slot |
| Combat actor cycle | A / D | Previous or next combatant |
| Inspector | Alt (hold) | The game's combatant dossier (the mod's I toggles it instead) |

One exception worth knowing: while the road map is open, the arrow keys browse the map and Ctrl belongs to buffer review, so the game's hold-Ctrl token glossary is unavailable there. WASD keeps driving the coach the whole time.

### On A Controller

A few recommendations if you are playing with a controller: on the road, the game's own pad layout already covers what the letter keys above reach, so none of it needs rebinding.

| Function | Default controller |
| --- | --- |
| Map | D-pad up |
| Goals panel | D-pad left |
| Token glossary | D-pad down |
| Stagecoach | D-pad right |
| Inventory | Y (Triangle on PlayStation pads) |
| Hero sheet | Select (also the touchpad press on PlayStation pads) |

The D-pad shortcuts answer while your focus is on the driving area; Tab into a HUD panel and the D-pad browses that panel until you Tab back to the road. Y and Select stay live the whole drive.
