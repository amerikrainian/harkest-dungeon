# Introduction

Harkest Dungeon is a screen reader and keyboard/controller accessibility mod for Darkest Dungeon II. It adds spoken output, focus navigation, contextual information buffers, gameplay event announcements, an audio layer for the road, and rebindable mod keybindings.

## Features

- Speech output through Prism, with support for common screen readers and speech backends.
- Keyboard and controller navigation for menus, the Crossroads, the road, inns, combat, loot and stories, the hero sheet, Kingdoms, and the Altar of Hope.
- Contextual buffers for the focused element, skill upgrades, hero vitals, both sides of a battle, the combat log, and subtitles.
- Combat and party event announcements: damage, tokens, dots, deaths, quirks, stress, affinity - the game's own pop text, spoken.
- An audio cue engine for the road: turning cues, edge bumps, and positional pings for roadside pickups.
- Glance keys that answer questions ("how is the flame doing?") from anywhere without moving your focus.
- Rebindable mod keybindings for keyboard and controller.
- The mod speaks whatever language the game is set to, covering all fifteen the game ships.
