# Changelog

Release notes, one `## V<version>` section per release; create-release.ps1 lifts the
tagged version's section into the GitHub release body, which the installer shows as
"what's new" after an update.

## V0.2.0

Initial release. Spoken navigation for the main menu, settings, pause menu, dialogs,
the crossroads, hero sheets, combat, loot, road stories, the road itself (audio cue
engine), inns, and Kingdoms (menu, creation wizard, overworld map, inn panels) - see
docs/accessibility_audit.md for per-screen status. Ships BepInEx and the Prism speech
backend; installs with the standalone installer.
